# ruby-synthesizer

Typed AST for structurally correct Ruby code generation from Rust.

Ruby is a build artifact -- authored in Rust, materialized as Ruby,
proven by 173 tests. Syntax errors are **impossible** at the Rust compiler level.

## The Key Insight

This is not a code generator that concatenates strings. It is a **typed computation
bridge** where the Rust type system enforces structural correctness:

- `RubyNode` (25 variants) makes invalid nesting a compile error
- `RubyType` (7 variants) guarantees well-formed Dry::Types expressions
- `emit_file()` deterministically converges the AST to Ruby source
- Property tests (proptest) verify every structural invariant

You cannot produce a `class` outside a `module`, an `attribute` outside a `class`,
or an unbalanced `end` -- the type system prevents it.

## RubyNode -- 25 Variants

Every Ruby construct has a typed variant. No string concatenation, no format strings.

| Category | Variants |
|----------|----------|
| Pragmas & comments | `FrozenStringLiteral`, `Comment`, `Blank` |
| Imports | `Require`, `RequireRelative` |
| Declarations | `Module`, `InlineModuleDecl`, `Class` |
| Statements | `Include`, `ConstAssign`, `Attribute`, `DefineResource`, `DefineData`, `RegistryCall`, `Raw` |
| RSpec | `Describe`, `SharedExamples`, `Context`, `It`, `ItBehavesLike`, `Let`, `Expect` |

## RubyType -- 7 Variants

Maps directly to Ruby's `Dry::Types` type system:

| Variant | Ruby output | Example |
|---------|-------------|---------|
| `Simple(name)` | `T::String` | `RubyType::simple("T::String")` |
| `Array(inner)` | `T::Array.of(T::String)` | `RubyType::array(RubyType::simple("T::String"))` |
| `Hash` | `T::Hash` | `RubyType::Hash` |
| `Union(variants)` | `(T::String \| T::Integer)` | `RubyType::union(vec![...])` |
| `Constrained { base, constraint }` | `T::String.constrained(...)` | `RubyType::constrained(base, "gt?: 0")` |
| `Optional(inner)` | `T::String.optional` | `RubyType::optional(inner)` |
| `Any` | `T::Any` | `RubyType::Any` |

### Lattice Properties

`RubyType` forms a partial order with lattice properties:

- **Optional lifts**: `optional(x) >= x` -- accepts strictly more values
- **Constrained narrows**: `constrained(x, c) <= x` -- restricts the base
- **Union is upper bound**: `union(a, b) >= a` and `union(a, b) >= b`
- **Optional is idempotent**: `optional(optional(x)) == optional(x)`
- **Array is monotone**: ordering on inner types is preserved through `Array`

See [docs/type-lattice.md](docs/type-lattice.md) for the full theory.

## Usage

### Direct AST Construction

```rust
use ruby_synthesizer::{RubyNode, RubyType, emit_file};

let file = vec![
    RubyNode::FrozenStringLiteral,
    RubyNode::Require("dry-struct".into()),
    RubyNode::Module {
        path: vec!["MyModule".into()],
        body: vec![
            RubyNode::Class {
                name: "MyClass".into(),
                parent: Some("BaseClass".into()),
                body: vec![
                    RubyNode::Attribute {
                        name: "name".into(),
                        type_expr: RubyType::simple("T::String"),
                        required: true,
                    },
                ],
            },
        ],
    },
];

let ruby_source = emit_file(&file);
```

### TypesFileBuilder

Generates a complete Pangea types file with enforced structure:
`frozen_string_literal` -> `require` -> `module` -> `include Dry.Types()` -> `class` -> `attributes`

```rust
use ruby_synthesizer::builders::TypesFileBuilder;
use ruby_synthesizer::RubyType;

let source = TypesFileBuilder::new("aws")
    .class("VpcAttributes", |c| {
        c.attribute("cidr_block", RubyType::simple("T::String"), true)
         .attribute("tags", RubyType::Hash, false)
    })
    .emit();
```

Produces:
```ruby
# frozen_string_literal: true
# Code generated by pangea-forge. DO NOT EDIT.

require 'pangea/resources/base_attributes'

module Pangea::Resources::AWS::Types
  include Dry.Types()

  class VpcAttributes < Pangea::Resources::BaseAttributes
    T = Pangea::Resources::AWS::Types

    attribute :cidr_block, T::String
    attribute? :tags, T::Hash.optional
  end
end
```

### ResourceFileBuilder

Generates a complete Pangea resource file with `define_resource`, `include`, and registry call:

```rust
use ruby_synthesizer::builders::ResourceFileBuilder;

let source = ResourceFileBuilder::new("porkbun", "porkbun_nameservers", "nameservers")
    .map(vec!["domain", "nameservers"])
    .emit();
```

### RSpecBuilder

Fluent API for constructing RSpec test files:

```rust
use ruby_synthesizer::RSpecBuilder;

let spec = RSpecBuilder::describe("'my class'")
    .it("works", |b| b.expect("result", "to eq(42)"))
    .context("when empty", |b| {
        b.it("returns nil", |b| b.expect("subject", "to be_nil"))
    })
    .build();
```

### Macros

Ruby-like syntax for inline AST construction:

```rust
use ruby_synthesizer::{ruby_module, ruby_body, ruby_parent, RubyType};

let node = ruby_module!("Pangea::Resources::AWS::Types" => {
    include "Dry.Types()";
    blank;
    class "VpcAttributes" < "Pangea::Resources::BaseAttributes" {
        const "T" => "Pangea::Resources::AWS::Types";
        blank;
        attribute "cidr_block", RubyType::simple("T::String");
        attribute? "description", RubyType::simple("T::String");
    }
});
```

## IaC Bridge (`feature: iac-bridge`)

Maps `iac_forge::ir::IacType` to `RubyType` with proven parity. This is the typed
bridge between the platform-independent IR and the Ruby type system.

```rust
use ruby_synthesizer::iac_bridge::iac_type_to_ruby;
use iac_forge::ir::IacType;

let ruby_type = iac_type_to_ruby(&IacType::String);
assert_eq!(ruby_type.emit(), "T::String");

let list_type = iac_type_to_ruby(&IacType::List(Box::new(IacType::Boolean)));
assert_eq!(list_type.emit(), "T::Array.of(T::Bool)");
```

The mapping is:

| IacType | RubyType | Ruby output |
|---------|----------|-------------|
| `String` | `Simple("T::String")` | `T::String` |
| `Integer` | `Simple("T::Integer")` | `T::Integer` |
| `Float` | `Simple("T::Coercible::Float")` | `T::Coercible::Float` |
| `Numeric` | `Union([Integer, Float])` | `(T::Coercible::Integer \| T::Coercible::Float)` |
| `Boolean` | `Simple("T::Bool")` | `T::Bool` |
| `List(inner)` | `Array(inner)` | `T::Array.of(...)` |
| `Set(inner)` | `Array(inner)` | `T::Array.of(...)` |
| `Map(_)` | `Hash` | `T::Hash` |
| `Object { .. }` | `Hash` | `T::Hash` |
| `Enum { values, underlying }` | `Constrained(base, ...)` | `T::String.constrained(included_in: [...])` |
| `Any` | `Any` | `T::Any` |

Proven properties: **injective** (different inputs produce different outputs),
**total** (every variant handled), **deterministic** (same input always produces same output).

See [docs/iac-bridge.md](docs/iac-bridge.md) for the full mapping analysis.

## The Convergence Pipeline

ruby-synthesizer implements the convergence pipeline at the language boundary:

```
declared        -> resolved           -> converged           -> verified
(Rust types)       (AST construction)    (emit_file())          (173 tests)
RubyNode enum      compile-time valid    deterministic Ruby     property tests
RubyType enum      builder enforced      trailing newline       lattice proofs
                                         balanced blocks        bridge parity
```

1. **Declared** -- Rust enums (`RubyNode`, `RubyType`) define the state space
2. **Resolved** -- AST construction is compile-time validated (invalid nesting = compile error)
3. **Converged** -- `emit_file()` produces Ruby source deterministically
4. **Verified** -- 173 property tests prove all invariants hold
